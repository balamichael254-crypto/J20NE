# Mood-board art

These are cropped from AI-illustrated moodboard collages the user supplied
directly in conversation (not sourced online). They are used as decorative
scene art throughout the app - moon skies, a lavender-in-a-jar still life, a
sleeping-bunny bedroom scene, a polaroid, a vinyl record, and a few small
lifestyle vignettes (notebook checklist, drink, rainy window).

Full-scene files (`bunny-porch-hero`, `bunny-loveheart-hero`,
`bunny-morning-hero`) are complete illustrations from the same set, kept
whole rather than cropped.

Not real photographs - matched in spirit to the app's own plush-bunny
character, not a substitute for it.

## Time-of-day hero set

`hero-morning.webp`, `hero-day.webp`, `hero-evening.webp`, and
`hero-night.webp` are used together as a single "hero image that changes by
time of day" on the home screen. Like everything else in this folder, they
are AI-illustrated moodboard art the user supplied directly in conversation
(not sourced online).

- `hero-morning.webp`, `hero-day.webp`, and `hero-night.webp` reuse the
  existing `bunny-morning-hero.webp`, `bunny-porch-hero.webp`, and
  `bunny-loveheart-hero.webp` files verbatim (resized/re-encoded only),
  saved under this new naming scheme so the four times of day line up
  consistently.
- `hero-evening.webp` is newly cropped and re-encoded from a wider
  sunset-bedroom illustration the user supplied separately (the full scene
  with the sleeping bunny, city-skyline window view, and polaroids),
  center-cropped to a matching portrait aspect ratio for this hero slot.
